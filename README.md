## 📌 Sobre o Projeto

O **Fnatic F1** é um portal de notícias e conteúdo sobre Fórmula 1, desenvolvido como trabalho final da disciplina de **Desenvolvimento de Interfaces para Web (DIW)** do **2º semestre** do curso de **Análise e Desenvolvimento de Sistemas** no **Centro Universitário Senac Porto Alegre**.

O projeto simula um hotsite completo de uma escuderia fictícia no universo da F1, com foco em semântica HTML5, organização de estilos e técnicas de layout sem uso de tecnologias modernas como Flexbox e Grid.

---

## ⚙️ Restrições Técnicas do Projeto

Este trabalho foi desenvolvido sob diretrizes acadêmicas que simulam restrições de arquitetura:

- 🚫 **Sem Flexbox ou Grid** — toda estrutura foi construída com **Float**, **Inline-Block** e **Clearfix**
- ✅ **Semântica HTML5** — uso de `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`
- ✅ **Separação de camadas** — HTML para estrutura, CSS para estilização
- ✅ **Foco em Desktop** — projeto desenvolvido para visualização em telas de desktop
- ✅ **Formulário validado** — cadastro com mais de 5 campos
- ✅ **Galeria** — mais de 4 imagens em páginas de conteúdo

## 📄 Páginas do Site

|---|---|
| `index.html` | Home com notícias em destaque |
| `senna.html` | Página dedicada a Ayrton Senna |
| `pequipes.html` | Apresentação das equipes da temporada |
| `hall-of-fame.html` | Hall da Fama com os maiores campeões |
| `historias.html` | Histórias marcantes da F1 |
| `calendario.html` | Calendário de corridas com bandeiras |
| `circuitos.html` | Galeria dos circuitos do campeonato |
| `resultados.html` | Resultados das corridas |
| `classificacao.html` | Classificação de pilotos |
| `classificacao-equipes.html` | Classificação de construtores |
| `nurbugring.html` | Página especial sobre o Nürburgring |
| `login.html` / `cadastro.html` | Autenticação de usuários |
