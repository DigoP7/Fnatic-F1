# Fnatic F1 - Portal de Notícias de Fórmula 1

Este projeto foi desenvolvido como trabalho final para a disciplina de **Desenvolvimento de Interfaces para Web (DIW)**, correspondente ao **2º semestre** do curso de **Análise e Desenvolvimento de Sistemas** no **Centro Universitário Senac Porto Alegre**.

O objetivo foi criar um portal de notícias funcional, focado na escuderia Fnatic no universo da Fórmula 1.

## 📋 Requisitos e Restrições (Escopo Acadêmico)

Para este projeto, foram estabelecidas diretrizes técnicas rigorosas que simulam o desenvolvimento de interfaces com tecnologias legadas ou sob restrições de arquitetura:

* **Foco em Desktop:** O projeto foi projetado especificamente para visualização em telas de desktop, seguindo o escopo definido para a disciplina.
* **Banimento de Flexbox e Grid:** O uso das propriedades modernizadas `display: flex` e `display: grid` foi expressamente proibido. Toda a estrutura foi montada utilizando técnicas de **Float**, **Inline-Block** e **Clearfix**.
* **Semântica HTML5:** Utilização de tags estruturais como `<header>`, `<main>`, `<section>`, `<article>` e `<footer>` para garantir acessibilidade e SEO.
* **Separação de Camadas:** Organização clara entre estrutura (HTML) e estilização (CSS).
* **Elementos Obrigatórios:** O site conta com 5 páginas/seções, galeria com mais de 4 imagens e um formulário de contato com mais de 5 campos validados.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de conteúdo.
* **CSS3:** Estilização avançada com foco em posicionamento por floats e containers fixos.
* **JavaScript:** Implementação de menus dropdown e interatividade básica.

## 📂 Organização de Arquivos

Seguindo padrões de organização profissional, o projeto está dividido em:
* `/css`: Folhas de estilo (style.css).
* `/img`: Ativos visuais e ícones.
* `/video`: Vídeos integrados das equipes de F1.
* `index.html`: Página principal e seções internas.
